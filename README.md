# nix-config

Personal config to install global system tools using Nix

## Usage

### Install

#### Local

```bash
cd ~
git clone git@github.com:f-hc/nix-config.git
nix profile add .
```

#### Remote

```bash
nix profile add github:f-hc/nix-config
```

### Upgrade

```bash
nix profile upgrade nix-config
```
